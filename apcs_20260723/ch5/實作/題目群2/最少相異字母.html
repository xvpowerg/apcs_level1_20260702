題目文字版：e313. 最少相異字母

        
      

      

        

          
題目內容

          

            
字串裡面如果有太多不同的字母，就比較不和諧。

            
現在有 N 個字串，要找出「不同字母種類最少」的字串。

            
如果有多個字串的不同字母數一樣少，就輸出字典序最小的那一個。

          

        


        

          
判斷規則

          

            

              1
              
先算每個字串有幾種不同字母，種類越少越好。

            

            

              2
              
如果種類數相同，再比較字典序，字典序較小的字串勝出。

            

          

        


        

          
輸入說明

          

            
第一行有一個正整數 N，代表接下來有 N 個字串，且 N ≤ 1000。

            
接下來有 N 行，每一行有一個字串。字串只會包含大寫字母 A 到 Z。

          

        


        

          
輸出說明

          

            
輸出最和諧的字串。

            
判斷順序是：先比不同字母數量，越少越好；如果一樣少，再比字典序，越小越好。

          

        


        

          
官方範例

          

            

              
範例輸入

              
3
ABBCAAB
AABBACC
AAPCCSS

            

            

              
範例輸出

              
AABBACC

            

          

        


        

          
範例白話說明

          

            
ABBCAAB 有 A、B、C，共 3 種不同字母。

            
AABBACC 有 A、B、C，共 3 種不同字母。

            
AAPCCSS 有 A、P、C、S，共 4 種不同字母。

            
前兩個都是 3 種，所以比字典序。AABBACC 比 ABBCAAB 小，因此答案是 AABBACC。
