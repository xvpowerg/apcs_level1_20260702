一句話：把每種伺服器擺法都算一次運費，最後選最便宜的總費用。
重要規則：輸入給的數字是「流量」，不是錢。錢是程式依照規則算出來的：同城市 ×1，不同城市 ≤1000 時 ×3，不同城市 >1000 時「前1000×3，多出來×2」。
這題只照下面 4 步走：
  1. 看這個方案：每台伺服器放在哪個城市。
  2. 根據伺服器的位置，把流量整理成「城市 → 城市」的總流量表。
  3. 根據費用規則，把每條路線的流量換成費用。
  4. 算出這個方案的總費用，最後找所有方案裡最小的總費用。
最重要的計算順序：每個方案都要重新整理一次流量。先把同一條「城市 → 城市」路線的流量加總，再判斷是不是同城市，最後才用規則把流量乘成費用。

題目白話說明

      
題目目標：有一些伺服器、有一些城市，題目給你幾個「伺服器放在哪個城市」的方案。請把每個方案的傳輸費用都算出來，輸出最便宜的費用。

      
四步主線：① 看方案：每台伺服器放在哪個城市。② 整理流量：把流量整理成「城市 → 城市」總流量表。③ 算費用：把每條路線的流量換成費用。④ 比最小：找所有方案裡最小的總費用。

      
一定要先懂的順序：不是一看到流量就馬上乘錢。要先把同一條路線的流量加總，再判斷同城市或不同城市，最後才套用費用規則。

      
輸入的流量不是錢：例如 30 23 23 表示伺服器 0 要送到城市 0、1、2 的流量，不是費用。

      
plan 怎麼看：plan 的位置 = 伺服器編號，plan 裡的數字 = 城市編號。例如 0 0：第 0 格是伺服器 0，數字 0 表示放城市 0；第 1 格是伺服器 1，數字 0 表示也放城市 0。

      
費用規則：同城市每單位 1 元；不同城市若流量不超過 1000，每單位 3 元；不同城市若流量超過 1000，前 1000 每單位 3 元，多出來每單位 2 元。

      
最後輸出：所有方案成本中的最小值。
