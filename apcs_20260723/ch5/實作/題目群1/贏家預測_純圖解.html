題目、公式與官方範例

一句話：玩家依照目前順序兩兩比賽，比較 S×T。比賽後兩人的能力都會更新，輸家累積失敗次數；失敗次數達到 m 就淘汰，最後留下的人獲勝。

淘汰規則

輸家失敗次數先加 1，再檢查：

條件結果
失敗次數 < m還沒淘汰，放入 loses，下一輪繼續比
失敗次數 ≥ m達到淘汰門檻，不放入 loses

勝負比較

玩家戰力應變力戰鬥值
p1aba × b
p2cdc × d

若 a×b ≥ c×d，p1 勝利；否則 p2 勝利。相等時算 p1 勝利。

p1 勝利時

對象更新內容
p1 新戰力a + (c×d) // (2×b)
p1 新應變力b + (c×d) // (2×a)
p2 新戰力c + c // 2
p2 新應變力d + d // 2

p2 勝利時

對象更新內容
p2 新戰力c + (a×b) // (2×d)
p2 新應變力d + (a×b) // (2×c)
p1 新戰力a + a // 2
p1 新應變力b + b // 2

重要提醒

  • a、b、c、d 是比賽開始前先保存的舊值，四個公式全部使用舊值。
  • // 是整數除法，只保留整數部分，不四捨五入。
  • wins 放「本輪優先進入下一輪的人」，包含本輪勝利者，也包含沒有對手而直接晉級的落單玩家。
  • loses 只放「輸了但還沒淘汰」的人。
  • 下一輪順序 = wins + loses。
