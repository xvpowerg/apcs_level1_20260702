題目文字版：贏家預測

一句話先懂：很多玩家排隊比賽，每場用「戰力 × 應變力」決定勝負，平手算前面的人贏，輸太多次就淘汰，最後剩下的人就是答案。
最重要的勝負規則：
  • 戰鬥值 = 戰力 \(S\) × 應變力 \(T\)。
  • 戰鬥值比較大的人贏。
  • 有平手；平手時算 \(p1\) 贏。
  • \(p1\) 不是一定指玩家 1，而是「這一場排在前面的玩家」。
w 和 l 是什麼？
  • \(w\) 是 winner，代表「這場的贏家編號」。
  • \(l\) 是 loser，代表「這場的輸家編號」。
  • w, l = p2, p1 不是交換玩家，而是貼標籤：p2 贏，所以 w=p2；p1 輸，所以 l=p1。
  • 後面 lCnt[l]+=1、wins.append(w)、loses.append(l) 都靠這兩個標籤處理。

有 \(n\) 個人要比賽，每個人都有戰力 \(S_i\) 與應變力 \(T_i\)。一開始會給一個比賽順序 \(idx\)。每一輪按照目前順序，兩個兩個配對比賽。如果某一輪人數是奇數，最後落單的人直接進入下一輪。

比賽勝負

假設第一位玩家的戰力與應變力是 \(a,b\)，第二位玩家是 \(c,d\)。比較：

\[ a \times b \quad \text{和} \quad c \times d \]

如果 \(a \times b \ge c \times d\)，第一位玩家勝利；否則第二位玩家勝利。平手時，前面的玩家勝利。

能力更新

第一位玩家勝利 \[ S_1 \leftarrow a+\left\lfloor \frac{c d}{2b} \right\rfloor \] \[ T_1 \leftarrow b+\left\lfloor \frac{c d}{2a} \right\rfloor \]

第二位玩家失敗：

\[ S_2 \leftarrow c+\left\lfloor \frac{c}{2} \right\rfloor,\quad T_2 \leftarrow d+\left\lfloor \frac{d}{2} \right\rfloor \]
第二位玩家勝利 \[ S_2 \leftarrow c+\left\lfloor \frac{a b}{2d} \right\rfloor \] \[ T_2 \leftarrow d+\left\lfloor \frac{a b}{2c} \right\rfloor \]

第一位玩家失敗：

\[ S_1 \leftarrow a+\left\lfloor \frac{a}{2} \right\rfloor,\quad T_1 \leftarrow b+\left\lfloor \frac{b}{2} \right\rfloor \]

能力更新要怎麼看

請注意：
  • // 是整數除法，只取整數部分，不四捨五入。例如 20 // 6 = 3。
  • a,b,c,d 是比賽前先取出的舊值，四個更新公式都用舊值計算。
  • 畫面會顯示「原公式 → 代入數字 → 整數除法結果 → 新的 S/T」。
例：如果第二位玩家勝利 
假設 a=4, b=5, c=2, d=3
S[p2] = c + (a × b) // (2 × d)
S[p2] = 2 + (4 × 5) // (2 × 3)
S[p2] = 2 + 20 // 6
S[p2] = 2 + 3
S[p2] = 5

括號很重要，(2 × d) 是分母，不是先除以 2 再乘以 d。

淘汰規則

每個人都有失敗次數。輸一場就加 1。若失敗次數達到 \(m\)，就淘汰。

每一輪結束後，下一輪順序是：

\[ \text{下一輪順序} = \text{勝利組} + \text{尚未淘汰的失敗組} \]
